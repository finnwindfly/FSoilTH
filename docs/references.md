# References and model context

FSoilTH documentation will maintain traceable references for every governing equation, parameterization and benchmark. This page will be populated as the scientific core is implemented.

## Comparison context

Planned model comparisons include process-rich frozen-soil models and land-surface schemes such as STEMMUS-FT, CryoGrid, CLASSIC and CTSM/CLM. Comparisons will distinguish equations, state variables, boundary assumptions, numerical methods, verification evidence and computational cost.

## Citation policy

Each implemented scheme must document:

- the primary source rather than only a later implementation;
- the exact equation and symbol mapping;
- unit conventions and parameter ranges;
- code location and version introduced;
- associated test or benchmark.

Before the first release DOI exists, cite the repository and exact Git commit. See `CITATION.cff` in the repository root.
